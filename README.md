# Bowons

**게임 프로그래머**를 목표로 학습과 프로젝트를 이어가고 있습니다.  
**Unity · Unreal Engine**을 활용한 게임 구현과 **네트워크 · DB · 멀티스레드** 등 CS 지식을 바탕으로  
안정적이고 몰입감 있는 사용자 경험을 만드는 데 집중하고 있습니다.

---

## 주요 게임 프로젝트
- **TANKS-Network (C#)** : Unity 기반 멀티플레이 탱크 게임 프로토타입
- **Codenames (C)** : SSL 세션 분리, SQLite 연동, Deadlock 해결 경험
- **Zombie-Panic (C++)** : 객체지향 설계 기반 간단한 좀비 슈팅 게임
---

## 기술 스택
- **언어** : C, C#, C++, Java, JavaScript, Python  
- **게임 엔진** : Unity, Unreal Engine  
- **네트워크 & DB** : TCP/UDP, SSL, SQLite, MySQL, Photon
- **협업 툴** : Git, PlasticSCM, Helix P4V
- **기타** : TouchDesigner, 영상 편집 등 미디어아트 프로그램 사용경험
